    │   ├── ipc_handler.c/.h            # IPC init, send log/resp

    │   └── debug.h                     # CM4_LOG macro

    │   └── mimxrt1170_evk_mimxrt1176_cm4_B.conf
    └── prj.conf                        # IPC, LOG, no UART_CONSOLE
Key Design Decisions
main() on CM7 returns immediately — IPC wait is in a separate preemptible thread so the shell initializes fully
CM4 has no UART — all output goes over IPC to the CM7 shell
IPC uses RPMsg/OpenAMP over shared OCRAM2 (two 32KB regions)
CM7 is host (role = "host"), CM4 is remote (role = "remote")
IPC Message Types
Type	Direction	Purpose
IPC_MSG_TYPE_CMD	CM7 → CM4	Shell command string
IPC_MSG_TYPE_RESP	CM4 → CM7	Command response
IPC_MSG_TYPE_LOG	CM4 → CM7	CM4 log messages
CM4 Commands Implemented
Command	Response
cm4 ping	pong
cm4 status	CM4 uptime: XXXX ms
